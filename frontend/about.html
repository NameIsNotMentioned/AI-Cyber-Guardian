About Cyber Guardian

Phishing and scam message detection

Project purpose

Cyber Guardian is designed to protect users from social engineering. By analyzing text patterns, URL structures, and psychological triggers, it provides a real-time risk assessment of incoming messages to help prevent credential theft and financial fraud.

Detection approach

The system uses a dual-layer detection strategy:

  • Rule-based engine: checks for known phishing signatures, urgency keywords, and suspicious URL patterns.
  • ML-based engine: a scikit-learn pipeline using TF-IDF vectorization and logistic regression to catch patterns rules miss.
